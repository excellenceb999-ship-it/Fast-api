# FastAPI + PostgreSQL Backend

A backend REST API project built using FastAPI and PostgreSQL.

## 🚀 Features

- FastAPI REST API
- PostgreSQL database
- SQLAlchemy ORM
- CRUD operations for products
- Pydantic models for data validation
- Database session management
- Interactive API documentation with Swagger UI

## 🛠️ Technologies Used

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
- Uvicorn
